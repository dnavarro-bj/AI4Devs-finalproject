# Cactify — Frontend

Nuxt 4 + Vue 3 + Pinia. Ver contexto del proyecto en el [README raíz](../README.md) y en [CLAUDE.md](../CLAUDE.md).

```bash
yarn install
yarn dev
```

Arranca en `http://localhost:3000`. Espera el backend disponible en `NUXT_PUBLIC_API_BASE_URL` (por defecto `http://localhost:8080`).
