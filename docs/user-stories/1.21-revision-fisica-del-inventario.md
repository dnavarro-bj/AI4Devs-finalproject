# 1.21 - Realizar una revisión física del inventario

**Tipo:** Could-Have
**Estado:** Núcleo — sin bloque asignado
**Ticket:** — (sin ticket todavía)

## Historia

**Como** propietario de un vivero
**Quiero** recorrer una localización comprobando ejemplar por ejemplar qué hay realmente allí
**Para** que el inventario del sistema coincida con el del invernadero.

## Criterios de aceptación

* La revisión se hace por localización.
* Cada ejemplar se marca como verificado, no encontrado o desplazado.
* Se pueden anotar ejemplares presentes que no están registrados.
* Al cerrar la revisión, las diferencias quedan a la vista antes de aplicar cualquier cambio.
