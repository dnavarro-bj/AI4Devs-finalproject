# 1.14 - Reprogramar, omitir o cancelar una tarea

**Tipo:** Must-Have
**Estado:** Núcleo — bloque 2
**Ticket:** [T-22](../tickets/T-22-tareas.md)

## Historia

**Como** propietario de un vivero
**Quiero** mover una tarea de fecha, saltármela o anularla
**Para** que el plan siga reflejando la realidad cuando cambia.

## Criterios de aceptación

* Una tarea pendiente se puede reprogramar desde la agenda y desde el calendario.
* Se puede omitir indicando opcionalmente el motivo, y cancelar.
* **Omitir o cancelar conserva que la tarea estuvo planificada** y no genera ningún cuidado realizado.
* Se pueden editar tipo, título, destinatarios, prioridad, fecha y notas mientras siga pendiente.
* Se pueden aplicar estas acciones a varias tareas compatibles a la vez.

## Notas

* Es lo que distingue «no se hizo» de «no hacía falta»: ambas cosas son información.
