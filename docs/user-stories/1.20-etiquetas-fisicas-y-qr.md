# 1.20 - Generar y escanear etiquetas físicas con QR

**Tipo:** Should-Have
**Estado:** Núcleo — sin bloque asignado
**Ticket:** — (sin ticket todavía)

## Historia

**Como** propietario de un vivero
**Quiero** imprimir una etiqueta con el código y un QR para cada ejemplar, y abrir su ficha escaneándolo
**Para** pasar del cactus que tengo delante a su ficha sin buscarlo.

## Criterios de aceptación

* Se pueden generar etiquetas físicas con el código de inventario y un QR.
* Escanear el QR abre la ficha del ejemplar.
* El código impreso coincide siempre con el del sistema y nunca se trunca.

## Notas

* Depende de que el código sea estable y no se reutilice ([1.1](1.1-asignar-codigos-de-inventario.md)): una etiqueta impresa no se puede renumerar.
* **Pendiente**: si el QR contiene solo el código o una URL directa a la ficha (§24.13).
