# 1.7 - Gestionar las fotografías de referencia de una especie

**Tipo:** Should-Have
**Estado:** Núcleo — bloque 1
**Ticket:** [T-19](../tickets/T-19-fotografias.md)

## Historia

**Como** propietario de un vivero
**Quiero** asociar fotografías de referencia a cada especie del catálogo
**Para** reconocer el taxón y comparar mis ejemplares con su aspecto habitual.

## Criterios de aceptación

* Una especie admite una fotografía de portada y una galería de referencia.
* Cada imagen tiene texto alternativo y se puede reordenar.
* Se puede anotar autoría o procedencia cuando sea relevante.
* Las fotografías de especie **no** se mezclan con el seguimiento de ningún ejemplar concreto.

## Notas

* Requiere la decisión previa sobre almacenamiento de ficheros: formatos, tamaño, miniaturas, EXIF y borrado (§8.3).
