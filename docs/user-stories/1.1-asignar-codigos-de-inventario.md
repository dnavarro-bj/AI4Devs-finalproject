# 1.1 - Asignar códigos estables de inventario

**Tipo:** Must-Have
**Estado:** Núcleo — bloque 1
**Ticket:** [T-15](../tickets/T-15-codigos-de-inventario.md)

## Historia

**Como** propietario de una colección grande
**Quiero** que cada especie y cada ejemplar tengan un código corto y legible (`CAT-GRUSS`, `CAT-GRUSS-01`)
**Para** poder identificarlos de un vistazo, buscarlos por él e imprimirlos en etiquetas físicas.

## Criterios de aceptación

* La especie recibe un código único, propuesto a partir de su nombre científico y corregible antes de usarse.
* El ejemplar recibe el código de su especie más un número secuencial propio de esa especie.
* La secuencia es independiente por especie y el código crece con naturalidad al pasar de 99.
* El código de un ejemplar **no cambia nunca**: ni al editarlo, ni al moverlo, ni al cambiarle la especie.
* Un número asignado no se reutiliza aunque el ejemplar se archive, se venda o muera.
* Dos altas simultáneas de la misma especie obtienen códigos distintos y consecutivos.
* El código se puede buscar y nunca se muestra truncado.

## Notas

* Los ejemplares se etiquetan físicamente: renumerar en masa obligaría a reimprimir el vivero entero.
* **Pendiente**: si el código de una especie que ya tiene plantas puede cambiarse (§24.2 del [documento de producto](../producto/definicion-funcional-y-ux.md)). La recomendación es que no.
