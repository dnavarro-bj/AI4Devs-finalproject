# 1.13 - Completar una tarea registrando el cuidado realizado

**Tipo:** Must-Have
**Estado:** Núcleo — bloque 2
**Ticket:** [T-22](../tickets/T-22-tareas.md)

## Historia

**Como** propietario de un vivero
**Quiero** marcar una tarea como hecha y que eso deje constancia del trabajo real
**Para** que lo planificado y lo ocurrido no se confundan pero tampoco se dupliquen.

## Criterios de aceptación

* Completar una tarea crea o enlaza el registro correspondiente en el historial de cada planta afectada.
* Se registra cuándo se realizó realmente, que puede no ser la fecha prevista.
* Una tarea completada no se modifica en silencio: cualquier corrección conserva qué se registró originalmente.
* Un cuidado se puede registrar directamente, sin tarea previa.

## Notas

* **Ninguna automatización marcará jamás una tarea como realizada.** Podrá crearla o sugerirla, pero la confirmación humana es la que hace aparecer un cuidado en el historial.
* **Pendiente**: si completar crea siempre un cuidado o hay tareas administrativas sin efecto en el historial (§24.18).
