# F.3 - Consultar cuidados pendientes

**Tipo:** Must-Have
**Estado:** **Promovida al núcleo** — bloque 2 (era roadmap)
**Ticket:** [T-24](../tickets/T-24-dashboard-operativo-y-trabajo-por-lote.md)

> Es la base del Dashboard operativo: la portada responde «¿qué requiere mi atención?», no muestra métricas decorativas.

## Historia

**Como** propietario de un vivero
**Quiero** consultar qué cactus podrían necesitar atención hoy
**Para** organizar el trabajo diario del vivero.

## Posibles criterios futuros

* Días desde el último riego.
* Días desde la última fertilización.
* Plantas sin revisar recientemente.
* Plantas marcadas con incidencias.
* Ubicaciones con cuidados pendientes.

## Notas

* En el MVP, el sistema no "decide" tareas pendientes: solo muestra el historial ([0.5](0.5-consultar-historial-de-cuidados.md)) y las recomendaciones de IA por lectura ([0.4](0.4-obtener-analisis-de-ia.md)).
