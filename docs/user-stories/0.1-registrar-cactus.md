# 0.1 - Registrar un cactus

**Tipo:** Must-Have
**Estado:** En alcance del MVP

## Historia

**Como** propietario de un vivero
**Quiero** registrar un cactus con su especie, su localización y los datos que lo identifican
**Para** mantener un inventario organizado y poder reconocer cada ejemplar.

## Criterios de aceptación

* Se puede seleccionar una especie desde un catálogo.
* Se puede indicar un apodo y seleccionar una localización ([F.1](F.1-organizar-cactus-por-ubicacion-jerarquica.md)).
* El ejemplar recibe un código de inventario estable, generado a partir del de su especie ([1.1](1.1-asignar-codigos-de-inventario.md)).
* Se puede añadir una descripción y una o varias fotografías durante el alta ([1.8](1.8-galeria-fotografica-de-un-ejemplar.md)), sin que la fotografía bloquee la creación.
* Se pueden indicar mes y año de germinación y la procedencia cuando se conozcan ([1.2](1.2-registrar-germinacion-y-procedencia.md)).
* Se revisa la pauta heredada de la especie antes de guardar, y se sobrescribe solo lo necesario ([0.7](0.7-personalizar-cuidados-de-un-ejemplar.md)).
* La planta queda registrada y aparece en el listado de inventario.

## Notas

* La edición reutiliza este mismo formulario (§5.4 del [documento de producto](../producto/definicion-funcional-y-ux.md)); el código de inventario queda bloqueado y no se regenera aunque se cambie la especie.
* Al seleccionar la especie, el cactus hereda sus cuidados recomendados (ver [0.6](0.6-registrar-especie-y-cuidados-recomendados.md)).
* El cactus puede etiquetarse con tags para facilitar su búsqueda posterior (ver [0.10](0.10-etiquetar-cactus-con-tags.md)).
